Kamikaz

À propos

Kamikaz est un projet personnel destiné à pratiquer Git et GitHub tout en développant mes compétences en programmation.

Objectifs

- Apprendre à utiliser Git et GitHub.
- Maîtriser les commits et les branches.
- Comprendre les Pull Requests et la collaboration.
- Améliorer progressivement mes compétences de développeur.

Technologies utilisées

- Git
- GitHub
- JavaScript

Statut du projet

Projet d'apprentissage en cours de développement.

Auteur

Développeur en formation, passionné par la programmation et les nouvelles technologies.
